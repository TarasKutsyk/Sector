# owner_fit: a model of the owner (context pack template)

Read at session start. This pack describes who the agent works for: how the owner works best, how they fail, what to say when it happens. It is not a process document (the workflow files own process) and not a style guide (the style pack owns output form). It owns the interaction and what the agent says between execution sessions.
